# ToT Tools — Android

A native Android utility for working with Township save exports.

- App name: ToT Tools
- Version: 0.2.0-beta (pre-release)
- Minimum Android: Android 10 (API 29)
- Import: Township save ZIP exports and extracted save files
- Editor: Currency, gems, tools, and construction-material categories
- Export: Save an edited copy as a separate ZIP package
- Privacy: Local processing; no network permission; source files are never overwritten

Keep an untouched backup before using an edited file. Game compatibility and acceptance are not guaranteed.

## Build

The **Build ToT Tools APK** GitHub Actions workflow publishes the APK to the repository's Releases page.
