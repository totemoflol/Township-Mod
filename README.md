# Township-Mod

Research workspace for local APK inspection and UI / quality-of-life experiments targeting Township 40.0.1.

## Project layout

- `original/` — original APK/APKM reference (kept off the public repository)
- `mod-base/` — MOD APK reference (kept off the public repository)
- `source/` — extracted or reconstructed source material
- `mod-menu/` — menu and UI experiments
- `patches/` — documented patch files
- `scripts/` — repeatable analysis and build scripts
- `extracted/` — generated extraction output (not committed)
- `docs/` — notes, hashes, findings, and procedures

## Important

This repository is public. Do not commit APK/APKM binaries, signing keys, credentials, account data, or other proprietary / sensitive files here. Keep binary inputs on the VPS or another private storage location. Commit only original analysis notes, scripts, and patches that are appropriate to publish.

## Target

- Game: Township
- Version: 40.0.1
- Android package: `com.playrix.township`

No APK has been uploaded to this repository yet.
